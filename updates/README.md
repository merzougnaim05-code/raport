# تحديثات تطبيق سطح المكتب (فرع desktop-updates)

هذا الفرع يخدم التطبيق المكتبي فقط — **لا علاقة له بموقع الويب إطلاقًا**.

## الملفات
- `status.json` — مفتاح الإيقاف/التشغيل عن بُعد (`"enabled": false` يقفل كل نسخ المستخدمين عند تشغيلها التالي مع رسالتك).
- `manifest.json` — أحدث إصدار متاح: `version` + `url` (رابط zip مباشر) + `notes`.

## نشر تحديث جديد (3 خطوات)
1. في مجلد `desktop` شغّل: `node make-update.mjs` → ينتج `release/Raport-Update-<الإصدار>.zip`
2. ارفع ملف zip إلى هذا المجلد في الفرع عبر GitHub (Add file → Upload files).
3. عدّل `manifest.json`: اجعل `version` هو الإصدار الجديد و`url` رابط التحميل الخام للـ zip (raw.githubusercontent.com/.../Raport-Update-x.y.z.zip).

المستخدم يضغط زر **«تحقق من التحديث (الموقع)»** في التطبيق → ينزل ويثبّت تلقائيًا → «إعادة التشغيل».

يمكن أيضًا استعمال ملف zip يدويًا: زر **«تثبيت ملف تحديث»** (مفيد عبر USB دون إنترنت).
